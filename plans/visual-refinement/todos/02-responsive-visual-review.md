# 响应式与交互视觉复核

优先级：P1。执行选择：继承 `README.md`，当前解析为 Codex / `gpt-6-astra` / `xhigh`。

依赖 `01-editorial-visual-refinement.md` 完成并集成。本任务在一个 worktree 内完成；使用真实浏览器检查最终实现，做有证据的必要修正，并以验证报告和精选画面形成一个最终 commit。如果无需改业务代码，验证交付本身就是本任务的提交内容。

## T1 · 复核桌面、平板与手机的视觉结果

**要做什么**

- 阅读 [../plan.md](../plan.md) 和任务 01 的实施结果，从最新集成基线运行 `npm run build`，启动独立本地预览；只管理自己启动的预览进程。
- 对首页、`/blog/` 和两篇实际文章检查 1440×1000、768×1024、390×844；在 320×740 补查长标题、菜单与 CTA。
- 查看首页首屏、About、四张作品卡、文章区、仓库区和联系区，核对字重、字距、正文可读性、画面裁切、卡片高度与内容节奏。与任务 01 保存的同视口 before 截图对照，判断是否达到了可看出的视觉提升。
- 桌面与手机检查 `/work/zebra/`、`/work/starwreck/`、`/work/better-trigger/`、`/work/sangota/` 的首屏和返回入口，确认共享 CSS 没有造成布局或文字回归。
- 测量首页手机说明字号、页面横向溢出以及重要正文/交互颜色对比。代码块在自身容器内部滚动不视为整页溢出。

**预计修改的文件**

- `plans/visual-refinement/verification.md`
- `plans/visual-refinement/evidence/`（精选 after 截图，与 before 使用相同视口）

**验收条件**

- 报告明确页面、视口和结果；首页说明计算字号至少 15px，页面整体 `scrollWidth <= clientWidth + 1`，主要内容与操作没有相互遮挡。
- 首屏、作品区、文章入口的画面相比基线有明确改善；1440px 博客 hero 没有原先四行拥挤标题，两篇文章没有空白第三列。
- 普通信息文字目标对比至少 4.5:1、大号文字至少 3:1；对实际改变的主要文字与蓝色交互取样记录，不以装饰线条代替文字检查。
- 四个项目页的现有视觉身份、标题和入口可用，未为本任务重做它们的内容或图形。

**前置依赖**：`01-editorial-visual-refinement.md` 完成并集成。

## T2 · 验证交互、内容数量与降级表现

**要做什么**

- 用鼠标、键盘与移动视口复核首页锚点、菜单、作品入口、文章卡片、返回和联系方式；移动菜单关闭后不可被 Tab 聚焦，开启后操作可完成。验证邮箱链接或保护入口即可，不实际发送消息。
- 复核两篇文章的代码复制或已有回退、长代码块内部滚动、背景图与交互示例；仅报告真正执行的检查。
- 使用临时数据或临时浏览器脚本覆盖一、二、三、四篇列表，确认首页最多三篇与博客多篇布局均合理；不得提交占位文章或测试用正式数据变更。
- 验证仓库筛选及 API 不可用时的现有快照，保留链接和选中项表现。
- 分别测试普通动画、`prefers-reduced-motion: reduce` 和模拟 WebGL 初始化失败。记录重要内容、图形退化、导航操作、控制台异常；前后静态对照不能替代普通动画检查。

**预计修改的文件**

- `plans/visual-refinement/verification.md`
- `plans/visual-refinement/evidence/`（仅保留说明实际结果所需的少量状态图）

**验收条件**

- 原有导航、文章、仓库和邮件入口通过实际操作复核，键盘焦点清楚；没有假数据进入最终页面。
- 减少动画和 WebGL 不可用时重要内容与入口仍可使用；普通动画下无新增未捕获异常、遮挡或明显闪动。
- 报告区分通过、失败与未测，不用推断填写成功。

**前置依赖**：本文件 T1。

## T3 · 修正回归并交付验证证据

**要做什么**

- 针对 T1/T2 发现的、本次视觉范围内的具体问题做最小修正；问题属于更早的无关功能缺陷时只记录，不扩展为架构或业务重写。
- JSX / CSS 修正后重新构建并复查受影响页面；最后运行 `npm run build`、`git diff --check`。
- 完成 `verification.md`，用仓库内相对链接引用精选前后画面，写明视觉变化、命令结果、浏览器覆盖、修复点和仍存在的实际限制。
- 清理自己启动的浏览器与预览服务，确认没有临时正式数据或无关文件；以一个最终 commit 交协调器复核和集成。

**预计修改的文件**

- `plans/visual-refinement/verification.md`
- `plans/visual-refinement/evidence/`
- 有明确证据时：`src/App.jsx`、`src/index.css`、`src/blog/BlogPage.jsx`、`src/RepositoryField.jsx`，以及受共享样式影响的项目页 CSS。

**验收条件**

- 所有本轮视觉回归已修正并复查，最后构建和 diff 检查通过。
- 报告与截图可从仓库直接审阅；不把 `/tmp/` 的易失绝对路径作为交付链接，不提交大型整页截图合集或新增测试框架。
- 一个最终 commit，文件范围与本任务一致；不 push、发布或操作用户已有服务。

**前置依赖**：本文件 T1、T2。
